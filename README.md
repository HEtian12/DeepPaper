# DeepPaper

DeepPaper 是一款本地文献管理与 AI 论文解析软件，支持 DeepSeek 和豆包/火山方舟接口。

## 主要功能

- 批量导入 PDF 和图片，自动提取论文正文与元信息
- AI 提取动机、贡献、方法、数据集、指标、关键词和局限性
- 全文检索、关键词检索、合集、收藏与重复论文管理
- 基于 PDF.js 的内置阅读器，支持翻页、缩放和 PDF 内搜索
- PDF 正文支持普通文字选择与复制；已有语料库原文定位数据继续兼容
- 左侧文献工具栏、中间论文列表和右侧详情区域支持拖动调整宽度
- 从语料库定位回原论文页，选区与批注随文献库一起导入导出
- 针对单篇论文进行连续对话，并可附加图片
- 全库 AI：用自然语言同时检索全部论文，例如查找同时涉及“长尾分布”和“知识蒸馏”的论文
- 全库 AI 先在本地按标题、关键词、摘要、动机、方法、贡献、任务、领域、结果和全文召回候选，再交给当前接口综合判断

## 本地运行

```bash
npm install
npm start
```

## 检查与打包

```bash
npm run check
npm run smoke:pdf-reader
npm run dist
```

API Key 和论文分析结果保存在本机；调用 AI 分析或对话时，相关内容会发送到所选择的 API 服务商。全库 AI 不上传全部 PDF，只发送本地召回候选的精简解析字段。
