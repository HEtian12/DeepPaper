# 演示指南

状态：提供录制流程，尚未录制真实模型演示视频。

## 准备

使用独立文献库，导入 3-5 篇允许演示的论文：至少两篇共享研究主题，另选一篇无关论文。提前完成解析及语义索引。录屏中收起接口配置，不展示真实 Key 或私人文件路径。

建议查询：“找出同时涉及长尾分类和知识蒸馏的论文，并比较它们的方法与局限。”此示例需要演示资料中确实存在相关论文；具体查询应与准备的资料匹配。

## 两分钟流程

| 时间 | 演示动作 | 观众能核验的内容 |
| --- | --- | --- |
| 0:00-0:20 | 导入一篇 PDF，打开原文与解析结果 | 真实桌面文件处理和 PDF 阅读 |
| 0:20-0:50 | 输入跨概念查询，查看相关论文及段落 | 自然语言检索和证据片段 |
| 0:50-1:25 | 展示 Agent 的检索、阅读和比较步骤 | 工具执行轨迹与跨论文综合 |
| 1:25-1:45 | 点击一个引用跳转原文页，核对结论 | 引用可追溯，而非仅展示模型答案 |
| 1:45-2:00 | 查看证据不足提示或确认创建合集 | 能力边界及写操作人工确认 |

模型等待过程可剪辑，但应注明等待片段已缩短。展示失败或证据不足时保留真实状态，不用预制成功答案替代。

工程冒烟截图使用合成 PDF 和模拟向量，只作为自动化回归证据，不能用于宣称真实检索质量。质量评测完成后，在视频说明中链接固定版本的评测报告。
