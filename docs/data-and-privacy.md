# 数据与隐私

DeepPaper 采用本地优先存储，当前 AI 和 Embedding 功能仍依赖用户配置的服务商。

| 数据 | 存储或处理位置 |
| --- | --- |
| 原始 PDF | 用户选择的原文件路径；移动文件后可能需要重新定位 |
| 正文、页码索引、解析结果、语料、合集 | Electron 用户数据目录中的 localStorage |
| API Key 和接口设置 | 本地配置 localStorage，目前没有操作系统密钥加密 |
| 段落向量、模型名、Metadata | 本地 IndexedDB |
| 对话、全库 AI 和 Agent 历史 | 本地 localStorage |

这些浏览器存储由 Electron 用户数据目录管理，不在 Git 源码目录中。“保存在本地”不等于加密，能读取该用户目录的人可能读取其中配置和资料。

## 哪些操作会发送内容

- 论文 AI 解析：发送提取的论文文本；图片相关功能可能发送所选图片内容。
- 单篇对话、全库 AI 和 Agent：发送问题、相关历史以及选取的论文或段落文本。
- 语义索引构建：发送缺失 Chunk 的文本至 Embedding 服务；语义查询发送查询文本。
- 证据校验：发送问题、生成回答及引用原文片段至对话模型服务商。

全库 AI 和 Agent 不发送完整 PDF 文件字节，但被选中的正文文本仍会离开本机。接口服务商的数据处理规则由用户选择的服务决定。

## 导入导出与迁移

JSON 文献库导出包含论文记录及正文/解析结果、语料、合集、全库 AI 状态和 Agent 状态。它可能含有个人文件路径、研究问题及未公开内容，不适合作为公开仓库样例。

当前导出不包含 API 配置、原始 PDF 文件字节和 IndexedDB 向量缓存。迁移电脑后需要重新配置接口，复制或重新定位原始 PDF，并重新建立语义索引。备份完整 Electron 用户目录可能包含密钥，不应作为演示资料分发。

自动测试只使用代码生成的 PDF、合成文本和模拟 Embedding 服务，不需要使用个人论文或真实密钥。
